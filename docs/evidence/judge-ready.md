# 评审叙事与演示路径

## 30 秒版本

这是一个可审计的舆情分析教学原型。我们先复现了筛选统计失真、非法参数 500、未知话题伪造预测和模型评估泄漏等问题，再在同一套 10 个 API 场景下把合约通过率从 2/10 提升到 10/10。现在大屏会明确显示模拟/派生数据，数据不足时拒绝预测，模型指标只来自离线留出集报告。它证明了工程和评估链可以可靠运行，但尚未证明真实社交媒体业务效果。

## 3 分钟演示路径

1. 打开首页，先指向数据来源横幅，说明当前是 `synthetic / inferred`，不是实时全网数据。
2. 选择一个话题和日期范围，展示帖子与关联评论同步变化。
3. 选择无数据范围，展示 SIR/ARIMA 面板安全提示，而不是出现内置假曲线。
4. 展示 SIR 的“情景模拟”标签、拟合 NRMSE 和结论边界；展示 ARIMA 的 95% 区间和收敛状态。
5. 打开 `/api/model_metrics`：若离线报告未生成，展示 503 与运行命令；若已生成，展示固定种子、样本划分、F1 和混淆矩阵来源。
6. 运行 `python -m unittest discover -s tests -v`，以 7/7 测试和 10/10 合约收尾。

## 常见问题的证据化回答

- **你怎么知道问题存在？** 同一 Flask 客户端基线请求复现了 0 帖子但 8,000 评论、非法参数 500 和未知话题假预测。
- **为什么这是根因？** 代码分别直接读取全量评论、无校验 `int()`、空数据替换硬编码曲线；不是视觉层症状。
- **为什么不先接更多真实数据？** 当前没有合规授权、隐私审查和代表性保证；先修复会污染任何后续实验的测量链。
- **模型准确吗？** 当前不能给出新准确率；完整离线报告未生成，真实外部有效性未知。
- **SIR 是预测吗？** 不是因果预测，是基于本地讨论量形状的有界情景模拟，页面公开 NRMSE 和限制。
- **下一步是什么？** 获取许可清晰的目标场景数据，冻结独立测试集，与词典或传统分类器做同条件基线和消融，再做代表性用户任务测试。
