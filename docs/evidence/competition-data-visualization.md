## 数据与图表口径

- 离线案例 ID：`campus-public-opinion-v3`。
- 总样本：54 条；校园餐饮 28 条、信息服务 14 条、财务提醒 12 条。
- 来源：微博公开内容 19、RSS/媒体 14、校园论坛 13、新闻媒体 8。
- 时间：固定参考时间 2026-08-01 08:00（UTC+8），视图按观测跨度自适应为 6 小时、24 小时或 7 天分箱。
- 情感：演示数据使用 `scenario_label_for_demo`，不宣称为模型预测精度。
- 热度：样本量、互动量、负面比例、来源数和趋势组成的 0–100 描述性分数，不是事件发生概率。
- 风险矩阵：节点位置使用原始负面比例和热度分数；密集标签用引导线错位，不移动数据点。
- 关系网：仅表示“数据来源—聚合事件”证据归属，不是转发链、因果网络或传播路径。
- 可访问性：SVG 含 `title`/`desc`、键盘焦点和直接标注；颜色不是唯一编码；复杂图表附数据表。

## 可复现验证

环境：Windows、Conda `cv`、`D:\an\envs\cv\python.exe`、Python 3.10.20。

```powershell
conda activate cv
python -m unittest discover -s tests -v
python -m compileall -q services web tests
node --check web/static/visualization.js
```

结果：

- 42/42 自动化测试通过。
- 新增后端竞赛模块语句覆盖率 93%（183/196）：`competition_demo.py` 100%，`visualization.py` 91%。
- 固定数据第一次加载新增 54 条；第二次新增 0、重复 54，监测项目 ID 不变。
- 可视化聚合为 3 个事件，样本数分别为 28、14、12，时间线与来源构成合计均为 54。
- 浏览器验收：1440×900 桌面端、390×844 移动端；移动端无页面级横向溢出，复杂 SVG 保持可读宽度并在卡片内滚动。
- 事件下钻验收：餐饮议题显示 4 个时间窗、4 类来源、2 类风险词和 28 条原始证据。
- 首次覆盖率尝试受 Windows 受限临时目录 ACL 影响，SQLite 无法创建测试库；改用项目内隔离且被 Git 忽略的 `runtime/coverage-temp` 后，3/3 竞赛测试通过并生成上述覆盖率。

## 尚未验证

- 合成案例只证明现场叙事和工程链路可重复，不证明真实平台覆盖率、准确率或舆情预测能力。
- 尚未由目标评委/分析人员执行理解度任务，也未完成 Firefox/Safari 真机检查。
- 真实微博采集仍需合规授权和人工扫码；验证码或访问控制不会被绕过。
- Docker/Redis/RQ 冷启动和持久卷重启需在已安装 Docker 的主机上另行验收。
