# 改进基线（2026-07-22）

## 项目与测量环境

- Git 基线：`fdd2069`（`main`），改进分支：`codex/evidence-driven-improvements`。
- 环境：Windows，Python 3.8.5；Flask、NumPy、SciPy、statsmodels、scikit-learn、jieba 可导入。
- 数据：本地 `data/raw` 中有 2,000 条帖子、8,000 条评论、300 个话题日序列；该目录被 Git 忽略。
- 数据来源状态：从 ID 格式和生成脚本可推断当前数据为模拟数据，但缺少机器可读的来源清单，因此此项状态为 `inferred`，不是 `verified`。
- 方法：使用 Flask `test_client()` 对当前代码执行固定 HTTP 请求；未启动外部 MongoDB，系统走本地 JSON 路径。

## 主要结果指标

主要指标是“关键 API 合约通过率”：请求必须返回约定的 JSON 状态码、不得静默替换数据，并保持筛选后计数一致。

| 场景 | 期望 | 基线结果 | 判定 |
|---|---|---|---|
| 未筛选总览 | 200 且计数可解析 | 200 | 通过 |
| 空结果总览 | 帖子与关联评论均为 0 | 帖子 0、评论 8,000 | 失败 |
| 非法开始日期 | 400 JSON | 200 | 失败 |
| 开始日期晚于结束日期 | 400 JSON | 200 | 失败 |
| SIR `days=abc` | 400 JSON | 500 HTML | 失败 |
| SIR `days=-2` | 400 JSON | 500 HTML | 失败 |
| ARIMA `steps=abc` | 400 JSON | 500 HTML | 失败 |
| ARIMA `steps=0` | 400 JSON | 200，并使用默认 7 天 | 失败 |
| ARIMA 未知话题 | 明确无数据，不生成预测 | 200，并静默使用内置曲线 | 失败 |
| 话题列表 | 200 JSON | 200 | 通过 |

基线：2/10（20%）。目标：10/10（100%）。

## 守护指标

- 合法总览、趋势、话题、词频、预警和预测请求不回归。
- `python -m compileall -q .` 保持通过（基线通过）。
- 新增自动化测试全部通过。
- 模型评估不在 GET 请求中训练或改写模型文件。
- 无数据时不展示未标注的模拟预测。

## 已复现的根因

1. `api_overview` 对帖子应用了筛选，但评论始终直接读取全部 `comments.json`。
2. 预测接口直接 `int()` 转换查询参数，没有类型或范围校验。
3. ARIMA/SIR 在筛选后无数据时使用硬编码曲线，响应没有来源标识。
4. 模型评估端点在每次 GET 中重新拆分、训练和写入检查点；词表在拆分前由全部文本构建，测试数据参与了特征空间定义。
5. 训练历史没有计算验证损失，但接口把训练损失复制成验证损失。

## 限制

- 尚无真实目标用户测试或官方比赛评分细则；“评审相关性”权重为临时推断。
- 尚未对真实社交媒体数据验证模型效果，不能把模拟数据结果外推为真实场景效果。
- 本基线没有执行原 `/api/model_metrics`，因为该 GET 会训练模型并覆盖本地检查点；这是由代码审计确认的副作用。
